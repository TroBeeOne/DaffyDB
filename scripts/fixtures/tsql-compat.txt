# T-SQL that DaffyDB translates, with the answer SQL Server gives. verify-tsql.ps1 runs each case
# through DaffyDB and compares the rows. "Ran without an error" proves nothing here: every case
# below that is about a wrong answer used to run cleanly.
#
# The expected rows came from SQL Server itself (LocalDB 17.0, us_english), and
# `verify-tsql.ps1 -Oracle` reruns the cases there to check them again. Every case is written to run
# unchanged on both, which is why the data comes from VALUES lists rather than tables.
#
#   ## name [flags]     starts a case; the SQL follows
#   => a | b            one expected row; columns are separated by " | ", NULL is NULL, '' is empty
#   cols: a | b         expected column names, checked only when the case says [names]
#
# Flags: [names] also compares column names. [daffy] is DaffyDB-only, with no SQL Server
# equivalent to check against. [differs] is a known, documented difference: the expected rows are
# DaffyDB's, and -Oracle shows SQL Server's alongside.
#
# Values are compared as text: dates as yyyy-MM-dd[ HH:mm:ss[.fff]], decimals without trailing
# zeros, bit as 1 or 0.
